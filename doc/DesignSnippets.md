## 目标与边界

支持补全函数调用、配置项和模板后连续填写参数，以及应用直接插入片段。
解析结果是不可变普通数据，可跨视图复用；填写会话归 SourceView，每个视图独立。
不在 Document、语言注册表或 GOUI typography 中保存片段交互状态。
不提前增加多光标、片段目录、变量服务或 LSP 连接。

## 公共接口提案

```go
func ParseSnippet(text string) (*Snippet, error)

func (v *SourceView) InsertSnippet(snippet *Snippet) error
func (v *SourceView) SnippetActive() bool
func (v *SourceView) NextSnippetPlaceholder() bool
func (v *SourceView) PreviousSnippetPlaceholder() bool
func (v *SourceView) CancelSnippet()
```

`Snippet` 的字段私有。解析不访问窗口或模型；无效语法返回错误，不留下半成品。
InsertSnippet 替换当前选区，空指针是参数错误；无占位符的片段等同一次普通文本插入。
跳转返回是否处理；取消幂等，保留已有正文，不自动跳到最终光标。

未来在 Completion 增加 `Snippet *Snippet`。非 nil 时不能同时指定 Text/Caret；
Label 仍用于显示，Range 决定替换范围，AdditionalEdits 仍可添加 import 等文本。
普通 Completion 的空 Text 使用 Label 契约保持不变。ui 同步别名、解析函数和命令，
不复制会话状态；不增加声明式“当前片段”属性触发重复插入。

## 语法与坐标

| 语法 | 行为 |
| --- | --- |
| `$1`、`${1}` | 编号跳转位置 |
| `${1:name}` | 默认文本为 name 的占位符 |
| 重复 `$1` | 同一组的镜像位置 |
| `$0` | 最终光标位置；到达后结束会话 |
| `\$`、`\\`、`\}` | 转义字面字符 |

正编号按数值升序跳转，0 最后；未写 0 时以插入末尾作为终点。
同一编号最多一处定义默认值，其他引用展开为相同内容；重复定义、多个 0 或非法编号报错。
先解析完整输入再解析引用，允许引用出现在默认值之前。
首版不支持选择列表、嵌套占位符、变量和正则转换，遇到这些语法明确拒绝。
应用可提前生成日期、路径等内容，并对作为字面文本嵌入的特殊字符转义。

正文沿用 UTF-8/LF；所有范围均针对展开并规范化后的文本，不直接使用模板字节位置。
空占位符、相邻零长度位置、换行、中文、组合字符和转义必须有独立预期测试。
文本大小、占位符数量和镜像数量必须有上限；具体预算恢复实施时经测试确定，超限原子失败。

## 会话与编辑事务

- 插入片段及附加编辑组成一次事务；先验证所有范围，再映射主插入位置和占位符。
- 仅主占位符持有真实选区；镜像通过同一次批量编辑更新，不通过修改信号递归补写。
  主位置和镜像一次撤销，其他视图和订阅者不能观察到半更新的正文。
- 普通输入、退格、删除、剪切、粘贴和配对操作统一核对当前占位符边界；
  可在主范围内表达的变更同步镜像，跨界操作先退出会话再按普通编辑执行。
- IME 预编辑只显示在主位置，正式提交后同步镜像；取消预编辑不修改镜像。
- 会话期间编辑范围需要明确起止边界的插入归属，不能仅按累计字节差平移全部位置。
- 第一批 Undo/Redo 退出会话，但正确恢复正文及选区；不复活旧占位符状态。
- 切文档、切语言、只读、禁用、失焦或卸载结束会话。来自其他视图或外部 API 的修改
  也结束会话，不能仅凭修改位置猜测它是主占位符输入。
- 输入过程中插入新片段先结束旧会话；第一批不维护嵌套会话栈。
- 外部回调后重新核对文档、修订、会话身份和挂载状态；关闭旧交互不能操作新文档。

## 键盘与呈现

补全弹窗先处理接受/关闭，再由片段处理 Tab、Shift+Tab、Escape，最后进入普通编辑。
片段会话与单行/多行影子建议互斥：插入片段先清除建议及虚拟高度，片段活动期间不接收影子建议。
不能让一次 Tab 同时接受影子文字和跳过占位符；恢复实施时同步核对输入优先级与快照语义。
Tab 向后，Shift+Tab 向前；首位置 Shift+Tab 保持首位置，不缩进正文；到达 0 结束。
Escape 先关闭补全，下次再取消片段；没有会话时保持现有缩进和焦点行为。
片段动作接入既有 Command/KeyBindings；实现时明确条件绑定与应用重绑定的优先级，
不新增另一个快捷键开关或默认 Ctrl+Space。

当前占位符使用真实选区，其他占位符可用轻量边框提示；不覆盖语法前景。
装饰只覆盖可见区域，通过 Basic/Modern 注册样式，不为装饰伪造可执行语义动作。
片段数据不持有原生布局；视图关闭释放会话、连接和装饰缓存。

## 参考与取舍

2026-11-04 核对，未执行参考编辑器的性能或跨平台对比：

- [VS Code 片段语法](https://code.visualstudio.com/docs/editing/userdefinedsnippets)
  描述编号、默认值、镜像和最终位置。采用基础语法子集，明确不承诺全部 TextMate 兼容。
- [VS Code 1.105.0 SnippetController2](https://github.com/microsoft/vscode/blob/1.105.0/src/vs/editor/contrib/snippet/browser/snippetController2.ts)
  的 _updateState 检查撤销到插入前、最终位置及选区离开占位符；监听模型切换和清空。
  这是该版本源码行为。采用显式会话失效，首版 Undo/Redo 一律退出是本项目取舍。
- [GtkSourceView 5.22.1 Snippet](https://gnome.pages.gitlab.gnome.org/gtksourceview/gtksourceview5/class.Snippet.html)
  支持解析、应用直接插入和片段引用。采用不可变解析数据与视图内会话，不照搬 GObject 管理器。
- [Scintilla 自动补全](https://www.scintilla.org/ScintillaDoc.html#Autocompletion)
  是候选选择与插入的参考，不据此推断它承诺与 VS Code 相同的片段会话。
  SourceView 的镜像和历史语义需由本项目独立验证。
