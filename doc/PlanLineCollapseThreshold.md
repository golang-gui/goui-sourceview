# 长行收起门槛验收

2026-11-10；实现前基线 `df6aea3`。对应 [长行收起设计](DesignLineCollapse.md)。

## 行为

首次收起条件从“段落高度至少是基准行高的 8 倍”调整为“已缓存的原生几何确认至少 3 个显示行”。
实际只有 1～2 个显示行时不提供长行收起入口；结构折叠仍按逻辑行范围提供入口。
已收起的行即使变宽后不足 3 行，仍保留箭头、菜单和省略标记用于展开。展开后按当前原生几何重新判断。
3 行是本项目的交互取舍，未将其表述为 Monaco / Scintilla / GtkSourceView 的标准，相关核对见设计文档。

分页长行先检查当前缓存的原生显示窗口，必要时读取已经缓存的首页几何。只需要证明至少存在 3 个实测显示行，
不计算全文总显示行数，不使用估计高度，也不为入口判定创建原生排版或读取未测量正文。
沿用 GOUI v0.7.0 的公开 `Geometry.LineCount` 与 `ParagraphLayout.CachedGeometryAt` 契约，无 GOUI 仓库改动或新增功能缺口。

## 单元与原生排版

[`line_collapse_threshold_test.go`](../line_collapse_threshold_test.go) 覆盖：

- 用原生字形宽度构造并明确断言 1 / 2 / 3 / 4 / 8 个显示行，逐项检查 API、命令/菜单状态、箭头命中及语义快照。
- 将高度估计故意放大或缩小，确认实际行数仍决定门槛；查询不得分配额外原生排版。
- 从 3 行收起后变宽到 1 行，箭头、菜单和省略标记仍可展开；展开后收起入口消失，原文/修订/历史不变。
- 分页活动窗口和缓存首页的几何证据；候选判定不依赖全文高度估计。
- 截图对应的两逻辑行 JSON：第 1 行对象箭头、第 2 行字符串箭头，点击分别控制正确范围。

上述新测试先在基线实现上运行，明确复现 3/4 行不允许收起、2 行被放大高度误判、分页状态依赖估计高度、
变宽展开场景无法开始及 JSON 字符串缺少箭头；改动后全部通过。

## 本机独立窗口

扩展既有 [`tests/window/editor/fold_preview`](../tests/window/editor/fold_preview/main.go)，保留原有大 JSON、结构预览、
搜索、编辑撤销和变宽/变窄断言，新增真实 1/2/3 行 JSON 和独立字符串箭头场景。
Painter 观察器直接核对绘制段落的原生行指标，并逐帧检查收起正文存在且保持一行裁剪。

环境：Linux amd64、Go 1.25.8、Pango、私有 Xvnc 24-bit / Xfwm4 合成桌面；临时配置、认证、缓存和产物在仓库外。
正常 Window 指针事件点击第 2 行的字符串箭头，确认对象结构保持展开；变宽到 2 行后再次点击仍能展开，
此后仅保留第 1 行的结构箭头，点击它独立收起整个对象。各阶段均核对原文、修订和撤销状态不变。

四组均通过：软件 1× Light（含用户原始 JSON 的只读载入）、软件 2× Dark、OpenGL 1.5× Light、软件 1× Basic。
真实收起态绘制断言分别 54 / 46 / 57 / 55 次，共 212 次。原始 JSON 只读，结束后 SHA-256 未变。

独立 X11 客户区采样通过页脚帧号配对真实 Paint：

- 四组各 11 个收起阶段的首帧均捕获，共 44 个；预览区有文字，下方无隐藏正文泄漏。
- 四组各检查 1 / 2 / 3 行及变宽展开后的箭头，共 16 个场景；1～2 行只有根结构箭头，3 行有两个各在自己逻辑行上的箭头。

像素采用合成后的 8-bit RGB 转灰度。正文阈值为亮色 <161、暗色 >150；排除行号、边框和省略标记。
箭头在中心 10×10 DIP 区域取样，与该行空白背景的灰度差 >40 计为笔画，存在需多于 2 像素，无箭头区域需为 0。
不使用跨字体金图，不放宽字体抗锯齿差异；原生行数由实际 TextLayout 指标另行断言。
已人工核对三行字符串的窗口截图。没有延长过渡帧或用离屏渲染替代真实窗口。

附带软件 1× 的原 `line_collapse` 和 `menus` 窗口回归均通过。前者会临时占有私有桌面的测试剪贴板，
随所属进程/桌面关闭，不影响用户工作桌面。结束后清理本次桌面进程和认证文件。

## 边界

上述原生运行结论仅适用于所列 Linux 后端、主题、字体和缩放。Windows/macOS 仅交叉编译，
未执行物理 IME、真实显示器 DPI 切换或硬件 GPU 验收，没有性能基准结论。
