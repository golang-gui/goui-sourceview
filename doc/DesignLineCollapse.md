# 长行收起

状态：已实现，验收见 [长行收起验收](PlanLineCollapse.md)。依赖仍为已发布的 GOUI v0.7.0。

## 范围

对自动换行后占据大量高度的单个逻辑行，提供手动收起能力。普通文本、单行 JSON、长字符串和压缩代码
共用同一显示策略，不增加语言解析器。手动长行意图与跨行结构范围分别保存，共用左侧箭头和首行预览。现有 Fold / Unfold / FoldAll / UnfoldAll
继续操作结构范围；FoldingEnabled 控制结构折叠与折叠栏的显隐，隐藏折叠栏不禁用显式长行 API / 菜单。
本轮不提供单行内部多个对象或字符区间的嵌套折叠。

默认全部展开。自动换行开启，当前宽度的已缓存原生几何已确认至少 3 个显示行，且正文宽度至少 64 DIP 时，
才允许初次收起。菜单仅在相关行上显示一个“收起长行”或“展开长行”项，位于结构折叠组之前；
同时在该逻辑行的首个显示行提供左侧箭头，不为获取入口而扫描或排版整个长行。分页段落检查已有活动几何或缓存首页是否包含至少 3 个显示行，不使用未测量部分的高度估计，也不计算整个段落的准确总行数。

## 统一折叠栏与结构首行预览

2026-11-10 修正：自动换行开启时预留折叠栏，包括无语言折叠器的普通文本。栏宽不随长行候选发现而变化，
避免“出现箭头 → 正文变窄 → 自动换行再次变化”的循环。实际只有 1～2 个显示行的展开行不显示长行箭头；首次收起使用上面的缓存几何门槛。
已收起的行即使窗口变宽后不足 3 行，也保留箭头、菜单和省略标记的展开入口；展开后重新按当前几何判断。

同一逻辑行最多一个箭头：有结构范围时优先操作结构，否则操作手动长行意图。已收起状态使用右箭头；
任一种意图存在时，点击箭头或预览省略标记一次展开该行的两种意图，只发布一次折叠变化。
每个逻辑行的软换行续行不重复显示箭头；后续独立逻辑长行仍可有自己的箭头。

自动换行开启时，结构收起也将其首逻辑行显示为一个原生显示行的预览，并隐藏原有后继逻辑行。
此首行预览由结构状态派生，包括只有少量软换行的首行，不要求手动长行的 3 行门槛。
短首行也共用预览省略标记，避免两个标记重叠；关闭换行时保留原有完整首行和结构省略标记。
结构分析器的逻辑行范围不变，不向语言层添加显示行范围或更深的语法解析。

结构派生预览不写入 `CollapsedLines()`。收起时隐藏的首行选区端点移至真实可见位置，搜索、选区或导航进入
首行隐藏后缀会展开结构；后继隐藏行仍沿用已有展开逻辑。其他段落的 IME 投影保持该预览，合成期间动作停用。
结构收起/展开沿用首次视口准备，以处理滚动条占位改变后的首帧；Paint 和快照不补测段落。

语义快照的箭头仍使用 `goui.sourceview.fold`，附加 `kind: "line" | "structure"`。
长行的 startLine/endLine 相同，结构范围保持真实逻辑行；collapsed 描述该箭头的组合收起状态。
禁用控件保留可见的箭头语义和绘制，但不发布可执行动作。预览省略标记按实际类型命名“展开长行”或“展开”。

2026-11-10 门槛调整：从“8 倍基准行高”改为“实际至少 3 个显示行”，验收见 [长行门槛](PlanLineCollapseThreshold.md)。
3 行是本项目的交互取舍：首次收起至少节省两行，1～2 行维持直接阅读；并非参考框架的标准。

## API 与所有权

- `CollapseLine(line int) bool`：零基逻辑行号，仅当资料已测量且满足条件时收起；不可操作或无变化返回 false。
- `ExpandLine(line int) bool`：清除该行的收起意图；只读可用，禁用或 IME 预编辑期不执行。
- `CollapsedLines() []int`：返回排序后的独立副本。修订已改变、但视图尚未观察到时不发布旧状态。
- `CommandCollapseLine` / `CommandExpandLine`：可通过现有 KeyBindings 自定义，默认不占用新快捷键。菜单使用
  GOUI Command/Shortcut 关联展示提示；声明式层只导出同名命令常量。
- 变化复用 `ConnectFoldingChanged`；字节选区的必要调整继续发布原选区信号。

每个 SourceView 保存自己的行号、字节范围和修订，Document 不保存该状态。不创建新文本副本，不改 Model 修订、
撤销历史或保存格式。单视图的操作不影响共享文档的其他视图。

窗口调宽或调窄时保留收起意图，按当前排版重算首行预览。临时关闭自动换行时显示完整逻辑行，恢复换行时继续收起。
修改被收起的逻辑行会展开；不相交的编辑按实际顺序映射字节锚点，仅保留能确认仍对应完整逻辑行的状态。
Reset、切换 Document 清空意图。同文档、同修订的卸载/重挂载保留；卸载期间文本有变化则清空。

## 布局、绘制与输入

保留原生段落、各宽度缓存和完整 Geometry；仅将 HeightIndex 中的有效高度设为首个原生显示行的实测高度。
正文和装饰裁剪到该行，预留可点击的省略标记；预览末尾对齐原生 shaping cluster 的可视边界，避免截断半个字形。
标记复用 Basic/Modern 的 fold-placeholder 颜色，悬停为淡色背景，复用完整选区的背景色。行号仍是真实逻辑行号。

分页段落只保持首页预览区域活跃；显式收起可按需准备首页，Paint、悬停和语义快照不补测。显式收起/展开及触及
已收起行的编辑使用已有首次视口初始化，使滚动条占位改变后仍能在首帧绘制当前宽度的文本。
已收起行遇到新宽度时，该行的排版在首次布局准备，以保持预览可见；普通段落、滚动及高亮继续沿用帧预算。
每次布局仍限于可见区域的有限轮次。普通原生段落的单次排版不可中断，不从预览只有一行推断其固定耗时上界。

- 收起时选区端点落入隐藏内容，则移到首行的可见光标位置，保留 bidi affinity。
- 首行点击仅命中预览区，省略标记单独命中，经正常 Window 指针事件展开。
- 显式选区、搜索、导航进入隐藏内容时展开。从后一段向上进入分页长行，定位真实末页的最后显示行。
- 两端都在可见行的跨行选区继续包含完整隐藏原文；复制、导出和保存仍使用真实模型范围。
- IME 开始前展开目标逻辑行，发布信号后核对修订和生命周期；不对回调替换的文档继续预编辑。
  其他已收起行通过投影行到源行的映射保持预览；预编辑增加换行也不会展开无关长行。合成期间标记动作停用，
  快照保守报告空的 committed VisibleRange，Preedit 另行报告。

语义快照在 goui.sourceview 中提供 collapsedLines；展开标记描述为真实可点击按钮，含本地化名称、边界和 Click 动作。
预览与其余可见原文以有界的 visibleSpans 分段报告，VisibleRange 保持真实连续范围，不用省略字符替换原文。

## 参考与取舍

### GOUI 组合裁剪限制与绕过

GOUI v0.7.0 的 `Painter.SetClipRect` 按契约替换显式裁剪，`ParagraphLayout.Paint` 内部又会设置各页裁剪；
当前没有传入外层预览边界的参数。直接嵌套 Save/SetClipRect 不能约束该内部裁剪，像素实测确认会泄漏隐藏的页内文字。
本组件仅在已收起的分页段落绘制时，传入私有 Painter 转发适配，将页裁剪与预览矩形取交集。
使用公开接口，不复制、反射或修改 GOUI 私有实现，不增加原生位图缓存。普通分页段落保持原绘制路径。

### 编辑器参考

2026-11-09 核对：

- [Monaco FoldingRange](https://microsoft.github.io/monaco-editor/typedoc/interfaces/editor_editor_api.languages.FoldingRange.html) 的 start/end 是逻辑行，
  [Scintilla Folding](https://www.scintilla.org/ScintillaDoc.html#Folding)（页面编辑日期 2026-10-01）的基础是文档行可见性。
  保留当前结构折叠的逻辑行契约，不将软换行变成语言的新折叠区域。
- [GTK4 显示行](https://docs.gtk.org/gtk4/method.TextView.forward_display_line.html)（API 4.0，页面 Library 4.24.1）明确说明显示行
  取决于视图宽度，段落取决于缓冲内容。保存逻辑行意图，由各视图原生排版决定预览，不保存易过期的显示行号。

“长行收起”是本项目的产品选择，不声称上述项目提供相同交互。没有使用其私有排版、文档或原生消息实现。

2026-11-10 再次核对上述 Monaco 官方 API、Scintilla `SCI_WRAPCOUNT` / Folding 与 GTK4 显示行文档：
继续保留逻辑行范围与宽度相关显示行的区分。结构首行压为单行预览、两种意图共用箭头是本项目的交互选择，
不声称参考编辑器已有相同的长行或组合收起行为。
