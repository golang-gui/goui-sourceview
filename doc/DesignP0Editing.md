# P0：折叠、缩进与单光标结构编辑

状态：P0 系列实施设计。本提交落地语言及外部折叠，编辑操作由后续提交落地。
本文以系列目标契约描述全部切片，不应把后续接口提前视为本提交已实现。
优先级依据见 [能力差距](DesignCapabilityGaps.md)。

## 2. 折叠语言覆盖

### 2.1 共同行为

沿用零基逻辑行、包含 EndLine 的 language.FoldRange。保留标题行，只隐藏后续行；
同起点只保留外层范围，允许严格嵌套，不允许交叉。末行若还有不属于该结构的正文，
收缩隐藏范围，避免连带隐藏其他语句。只有一行、没有可隐藏正文的结构不生成按钮。

每个扫描器使用自己的可靠引用/注释/块状态，不根据字符颜色或逐行正则猜括号。
后台分析只访问不可变输入，按有界输入进度检查 context。无完整闭合证据的括号块不隐藏；
缩进/节定义的边界可由下个同级结构或 EOF 确认，不要求虚构闭合符。

P0-A 不顺带增加注释连续行分组、所有格式的 region 或任意手工折叠，以免同标题争用。
已有 JSON/XML/HTML/Markdown 的边界与保守恢复保持回归测试。

### 2.2 JSONC / JSON5

复用参数化的 JSON 系列折叠扫描，而不把 JSONC/JSON5 都当严格 JSON：

- JSON：双引号字符串；JSONC：增加 //、/* */；JSON5：增加单引号、字符串续行等自己的词法规则。
- 只在真实代码上下文压入对象/数组栈；字符串、注释中的 `{ } [ ]` 不影响栈。
- 已闭合多行块注释可生成范围；与外层对象同标题时按统一外层规则处理。
- 块括号类型错配时仅保留已确认的完整候选，不制造穿过错配点的折叠。
- JSON Lines 保留按记录组织的定位，不把相邻记录合成一个范围；本切片不改变其既有规则。

固定样本覆盖注释中的括号、单双引号与转义、JSON5 续行、尾逗号、同一结束行上的后续内容、
未闭合结构和嵌套注释外观。折叠不替代严格语法验证。

### 2.3 YAML

采用与 YAML 词法规则配套的行结构分析，目标是确认可折叠的连续源范围，不构建完整 YAML 值树。

- 块映射/序列项：标题必须有确认的子内容；正文到下一个同级/外层有效条目前结束。
  `- key: value` 的序列缩进与条目内映射缩进分别处理，不能只比较整行前导空格数。
- `|` / `>` 块标量：尊重显式缩进指示和内容边界，内容中的 `#`、冒号、括号均是正文。
- 流式集合 `[]` / `{}`：只在已确认的非字符串/非注释上下文匹配；可跨行。
- 引用跨行、plain scalar 延续、复杂键等无法可靠判定的局部，保留原文可见，不套普通缩进猜测。
- `---` / `...` 文档边界不得跨越；Tab 不作为合法块缩进层级推算依据。
- 纯注释/空行不充当结构标题；块外的末尾空行和独立注释不吞入前一结构。
  两条确认正文之间的空行/注释随该结构隐藏；块标量内部按其词法归属处理。

验收样例要逐项给出 StartLine/EndLine，包含零缩进序列、嵌套映射、带缩进指示的块标量、
多文档、引用标量和编辑到半成品的状态。不能用“折叠按钮出现了”替代边界正确。

### 2.4 TOML

- 表 `[table]`、数组表 `[[table]]`：折叠其源文件中连续的正文，结束于下一个表标题前。
  不按 dotted key 的语义父子关系合并不连续区域；相邻无正文的标题不生成按钮。
- 引号键和标题内的 `]` 由词法处理，字符串/注释里看似标题的文本不创建范围。
- 多行数组和多行 basic/literal string 提供独立范围；字符串中的数组符号不参加匹配。
- 节外空白和独立的末尾注释不归入前一节；节内正文之间的注释保留。
- 以现有 TOML 扫描器支持范围为准，本轮采用 TOML 1.0 规则验证；不因折叠改动宣称完整支持新版规范。

### 2.5 常用代码语言（P0-E）

先覆盖 Go、JavaScript/TypeScript、CSS 和 Python，再逐语言启用其他已有词法器。
括号结构复用 ClassDelimiter 和引用/注释状态；语言没有可靠角色分类时先补分类测试，
不能全局给所有语言强装一个花括号扫描器。Python 的缩进块必须排除三引号和续行，
不同规则不共用“只看缩进”的开关。

region 仅在语言明确配置的注释行形态中识别，未闭合的不隐藏。跨越现有结构导致交叉的
region 舍弃而不是截断用户正文；首次启用不新增通用 region 优先级或分类枚举。

## 3. 外部折叠结果与可见状态

### 3.1 API

```go
// Folds 的字段私有，由构造器生成。
type Folds struct { /* 不可变候选与源范围索引 */ }
func NewFolds(text string, ranges []language.FoldRange) (*Folds, error)
func (d *Document) SetFolds(revision uint64, folds *Folds) (applied bool, err error)
```

保留既有 Language.FoldingFunc，作为默认来源。外部结果是 Document 的显式覆盖，不与默认
候选按隐含优先级合并。Snapshot 构造器与 Highlights 的取舍相同：把复制、排序、范围校验、
行号转字节位置放在 worker；不增加公共 Provider 注册中心或位置锚点体系。

NewFolds 接受准确的规范化 UTF-8/LF 文本，复制范围；排序、去重、同起点取外层并拒绝交叉、
越界和反向范围。应先规范化再判断有效候选数，不沿用当前 normalizeFolds 在去重前限制总数的
副作用。预计算标题/结束字节边界、文本长度和行数，不保留全文或原生对象。
构造 O(N + F log F)，N 为文本量、F 为输入范围数；构造时临时建立行起点表；返回值仅保存候选端点，不保留全文、逐行表或逐字节表。

SetFolds 仅在所属序列调用：旧 revision 返回 false,nil，当前长度/行数不匹配返回错误且保留旧值，
成功表示接受候选，视图可在后续事件循环完成状态协调。调用方另外核对 Document.ID 和分析代次；
相同长度/行数不能证明来源正确。nil 清除外部覆盖并恢复默认来源；非 nil 的空候选表示显式没有折叠，
不能回退内置。无需为“没有折叠”创造错误。

ui 提供 Folds、FoldRange 别名及 NewFolds 包装。候选归 Document，不增加 SourceViewView 的
平行候选属性；FoldingEnabled 和已有动作继续归视图。

### 3.2 状态和结果竞争

- 首次设置外部来源取消当前内置任务并提升结果代次；迟到的内置结果不能覆盖外部快照。
- 发布新结果不修改 Language/Revision/历史，不清理高亮、配对和补全；折叠关闭的视图也不丢失配置。
- 每个视图只继承旧位置仍有效、起止边界精确对应的 Collapsed 意图，禁止仅按行号或标题文本猜测。
- 外部模式下编辑：被直接触及的区域展开并失效，未相交区域按既有规则移动，等待新外部结果；
  不因快照变旧自动启用内置规则。
- SetText 清除旧候选，保留外部来源选择；换语言定义退出外部覆盖，防止新语言意外使用旧结构。
  应用随后可发布新语言的外部结果。
- 最后视图卸载停止 GUI 任务；配置不丢失。重挂载若错过修订，候选和旧折叠意图不继续隐藏正文。
- 清除外部来源时立即取消旧候选的隐藏作用，再请求默认分析；不会在默认结果未就绪时继续隐藏
  来源已被撤销的结构。nil 的语义因此不同于“外部新结果正在分析”。
- IME 覆盖期间延迟应用会改变可见映射的结果；结束后重新核验 revision/来源代次。
- 仅候选变化、可见行集合不变时，只刷新按钮与语义快照；实际可见映射变化才协调几何。
  光标/选区端点不得被新隐藏区域遮住；必要时展开该区域。无关候选发布不关闭补全。

继续使用 ConnectFoldingChanged。文档接受结果与每个视图呈现完成不是同一时刻，
每视图在一致的新状态生效后通知；回调后核验文档、挂载和代次，防止重入后继续提交旧布局。

### 3.3 大结果的准备与接收

现有 foldingStep 在 GUI 调 Model.Text，finish 在 GUI normalizeFolds，acceptFolds 逐范围
调用 LineRange 并为每个视图构建全部条目。这些步骤不能因扫描在 worker 就宣称“全程非阻塞”。

实现：

1. 内置全文快照按 revision 固定、使用 Model.Slice 在事件循环中分块复制（起始 64 KiB/步，
   rune 边界）；任一编辑/取消/销毁丢弃本轮，worker 仅组装已完成的普通字符串块。
   不导出新文本快照接口，不让 worker 读取活模型。
2. 内置分析后的规范化、字节端点和候选索引也在 worker 完成，与外部快照走同一接收路径。
3. GUI 每步协调有限候选/折叠意图（起始 256 项、2ms 软预算），只保留一个进行中的版本及最新请求。
   旧的有效可见状态保留，准备完成后整体替换，避免半份候选造成行映射跳变。
4. 最终交换仍进行 O(F) 的选区保护和隐藏行比较；只有隐藏集合变化才调用已有高度/可见索引重建。
   窗口验证包含这一步以及之后的绘制，2ms 不是最终交换的硬时间上限。没有增加 typography 接口。
5. 单次编辑仍为 O(F)，十万候选实测见验证记录。对单调不相交批次，按顺序归一化坐标，
   用编辑前缀差值和二分将原先 O(F×E) 降为 O(E+F log E)，包括撤销的升序通知。
   任意顺序的通知保留原有精确路径；未引入未经测量证明必要的通用追踪树。

时间预算是合作调度目标，不是原生调用或用户回调的硬时限。内存为最新快照、最多一个分析输入、
准备中索引及各视图必要意图；无历史快照队列。普通缓冲由所有者释放，原生布局继续归视图。

## 4. 单光标编辑

### 4.1 子词边界

新增 MoveWordPart(forward, extend bool)、DeleteWordPart(forward bool) error，及对应
左右移动、扩选、删除 Command。保留 MoveWord 原语义，不在旧快捷键上偷偷更换分词规则。

- 先遵守当前有效语言的 Word 谓词；只在一个合法词段内部细分。
- 小写到大写、字母到数字、数字到字母建立边界；连续大写后接小写时在最后一个大写前分段：
  `get|HTTP|Response|2`、`XML|Parser`。组合附加符属于前一个字母，不独立停靠。
- 若语言把下划线视作词字符，下划线连续段作为独立段：`foo|__|bar`。连字符按语言 Word
  规则先分词；不把所有语言统一改成标识符规则。
- 无大小写文字保持语言词段，不按字节拆中文；最终位置沿用原生 Cluster 合法停靠契约。
- 空白、标点和跨 LF 行为沿用现有 MoveWord/DeleteWord 的方向差异，软换行不创建词边界。
- 非空选区删除整段选区；普通移动先收起到方向端，扩选保留 Anchor。只读允许导航，不允许删除。

底层放 internal/editor/motion.go，按有界片段读取，不复制整条超长行。布局未就绪时复用
现有输入排队/GeometryAt 路径；不得为了一个子词动作强制排完整段落。

### 4.2 扩大/缩小选区

新增 ExpandSelection() bool、ShrinkSelection() bool 及对应 Command。
候选来自现有可靠词法/标签信息与纯文本范围，P0 不新增公共 SelectionRangeProvider：

1. 当前语言词段；
2. 能确认的字符串内容与包含引号的范围；括号内容与包含分隔符的范围；
3. 能确认的标签正文与完整元素范围；
4. 包含当前选区的逻辑行（不含 LF、含 LF 分别去重）；
5. 全文。

这不是固定顺序强套所有位置。候选必须严格包含当前整个选区，按最小外扩选择并构成嵌套链；
跨行选区不缩回单行。交叉/相等/非法 rune 边界丢弃。字符串里的括号、注释里的标签不参与。
只凭 FoldRange 的行号不能制造精确节点范围。

每视图保存本次实际选择轨迹，首项是精确原始 Selection（包括方向）。扩大保留既有方向，
空光标默认正向；缩小恢复轨迹上一项，不重新猜测。最多 64 层，预留全文终点。
任何外部选区变化、正文编辑、切文档/语言、IME 或卸载终止轨迹；颜色刷新不终止。
选区信号重入时旧轨迹立即失效；折叠端点按已有规则展开，复制仍包含真实连续正文。

结构查询复用现有两侧各 64 KiB 的匹配预算，不同步强迫全文高亮。缺少结构证据时可以采用
可靠的文本候选；未知词法段不参与结构匹配；采用已知的词、行或全文候选，不主动同步重建高亮，也不在用户后续动作后应用迟到选择。超出扫描范围的任意 AST 选择留给后续接口。

### 4.3 整理类命令（P0-E）

- JoinLines() error：非空选区处理所覆盖相邻逻辑行，末端恰在下一行行首时排除该行；
  无选区合并当前行和下一行。移除 LF 及下一行前导 ASCII 空白；接合两端均为非空白时插入
  一个普通空格，否则不补。这是显式文本操作，不猜标点或声明等价格式化；EOF 无操作。
- TransformCase(mode CaseMode) error：Upper/Lower，非空选区或光标所在语言词，采用 Go Unicode
  大小写映射，不做 locale、title-case 或语义重命名。按新 UTF-8 长度映射 Selection。
- TrimTrailingWhitespace() error：非空选区覆盖的逻辑行，无选区为全文；仅删除行尾 ASCII
  space/Tab，不删除 LF、NBSP 等。显式命令可改变有意保留的空白，默认不自动保存时执行。

都经现有 Plan/ApplyBatch 一次提交、一次撤销，保留方向和确定的编辑后选区。无变化不制造历史。
输入快照在事件循环中分步复制，整理计划在 worker 构造，revision/selection 变化即放弃；超限按操作预算报错，
不能分成多次用户可见修改来冒充一次事务。最终 ApplyBatch 的耗时也纳入大文件验收。

## 5. 缩进和输入辅助

### 5.1 不把三种操作混为一谈

| 操作 | 触发 | 修改范围 | 默认 |
| --- | --- | --- | --- |
| 普通 Enter | 真实键盘提交 | 原选区、必要的相邻空白、插入的新行 | 沿用现有自动缩进，并细化语言规则 |
| 重新缩进 | 显式命令 | 选中逻辑行的前导 ASCII 空白 | 不自动触发 |
| 按缩进粘贴 | 独立显式命令 | 新插入文本中允许调整的行首 | 普通 Paste 保持原文 |

不在后台着色完成后悄悄改正文，不把所有冒号都解释为新缩进，不对无法识别的半成品猜结构。
每种操作均受只读、禁用、IME、修订、选区和生命周期约束。大小文件遵守相同文本语义。

### 5.2 Enter 的语言规则

继续使用 language.EditingRules.Newline，不添加第二套通用输入回调。Known=false 或上下文
截断不足以判断时，仅复制可可靠取得的前导缩进，不同步扫描到文件开头。

- JSON 系列：已有空括号对展开保留；确认开块且未在当前位置闭合时，新行增加一级，
  遇到实际关闭侧按对应开块缩进。字符串/注释中的符号不触发。
- YAML：确认块映射键结束后进入下一层；序列项继续相同的 `- ` 前缀，空项退出一级。
  块标量正文 Enter 延续其内容缩进，不插入列表前缀；多行引用/plain scalar 使用自己的状态。
  `http://`、quoted key、flow mapping 的冒号不能触发块规则。
- TOML：表标题后的赋值与标题保持同层，不能像大括号语言默认加一级；多行数组可增加一级。
  多行字符串仅保留原输入规则，不重新对齐已有内容。
- XML/HTML：沿用标签规则，空元素、raw-text、注释/CDATA 和嵌入语言各自处理。
- Markdown：保留已有列表/引用继续与空项退出；围栏内委托已知子语言，未知围栏不套 Markdown 列表策略。
- Go/JS/TS/CSS 和 Python 在 P0-E 独立增加样本；Python 冒号必须来自确认的块头而非切片、
  字典或字符串。优先使用已有 Context 数据和私有状态，不为几个内置规则建立公共 AST。

TabWidth 解释已有 Tab 的列，IndentWidth 定义新增一级；生成空白遵守 InsertSpaces。
Makefile 的 recipe Tab 不在通用规范化范围，未来规则需显式保护。

### 5.3 重新缩进的应用契约

命令 `SourceView.ReindentSelection() error`：非空选区覆盖的逻辑行，末端位于下一行
行首时排除该行；空选区只处理当前行。全文操作通过先 SelectAll 显式表达。
已有 Indent/Outdent 仍是机械增减缩进，不改成语法重新缩进。

为让自定义语言获得相同能力，在 language.EditingRules 增加一个可选回调：

```go
// 只含普通值，不引用活模型。
type ReindentContext struct {
    Text               string
    StartLine, EndLine int // 零基逻辑行，包含末行
    TabWidth, IndentWidth int
    InsertSpaces       bool
}
type LineIndent struct {
    Line int
    Text string // 目标完整前导空白，只允许 ASCII space/Tab
}
type ReindentFunc func(context.Context, ReindentContext) ([]LineIndent, error)
// EditingRules.Reindent ReindentFunc
```

返回目标前导空白而不是任意正文编辑，便于限制职责。结果应按行递增且不重复，必须落在请求
范围内；没有返回的行保持原样。nil 回调或空结果都是正常无修改。自定义回调与输入配置必须
可安全并发，不能读取 GUI 对象；无法确认的行不返回结果。通用格式化继续由应用 ApplyEdits。

内置重新缩进仅处理能确认结构的行。JSON 系列、标记标签和已确认代码块优先；YAML 缩进
本身决定语义，不能根据“看起来不齐”重新解释树，无法确定时不调整；TOML/YAML/Markdown
中作为数据的多行内容必须保护。此命令不承诺修复语法错误。

方法返回 nil 表示无修改或请求受理，不等于异步任务已经执行完。快照按 §3.3 分步复制，
回调在一个 worker 执行；每视图只保留一个运行任务及最新请求。worker 验证返回列表并准备原坐标 Plan；GUI 检查文本身份/修订、语言/选项代次、选区和挂载状态后一次 ApplyBatch。
候选超限/非法回调结果经 ConnectError 报告，过期或取消正常丢弃。真实失败不先改部分正文。

等待时允许继续编辑；新的输入、Undo/Redo、普通选区移动、IME、只读/禁用、切文档/语言和
卸载取消旧请求。按钮不需要忙等或冻结控件。应用若需要立即执行已算好的结果，可使用既有
ApplyEdits，不再增加同步版本。逻辑规划器单独测试，不能为了测试导出任务内部状态。

### 5.4 按缩进粘贴

新增 PasteReindented() error 和 CommandPasteReindented，无默认快捷键。复用既有剪贴板
读取、revision/selection 核验、错误反馈和正常 Commit 路径的共用事务设施，不调用普通 Paste
落盘后再改第二次。粘贴内容规范化与普通 Paste 一致。

第一阶段只做 **相对缩进平移**：

- 目标位于前导缩进/确认的行首插入位置时，将多行片段的公共前导缩进平移至目标基线，
  内部相对列差保持。首行接在目标已有缩进后，不重复插入目标前缀。
- 光标在已有语句中间、范围跨越未知上下文、词法状态未知时按普通 Paste 原样插入。
- 剪贴板片段或目标上下文涉及多行字符串、YAML 块标量、Markdown 围栏/缩进代码、Makefile
  recipe 等不能证明平移安全的内容时，整次退回原样粘贴，不仅保护几行而改变其边界语义。
- 不能因为整列不对齐而展开正文中的 Tab；只改可调整的行首 ASCII 空白。
- 不改选区外的原有前缀/后缀，不补或删 EOF 换行；最终一次事务，Undo 恢复粘贴前完整选区。

这是用户显式选择的辅助操作，不保证语义等价或完整格式化；不会增加默认开启的自动粘贴改写。
单行粘贴/保护路径直接复用原行为；大载荷分析和计划分步，文档变化时不能把迟到剪贴板结果
插入新光标位置。失败只报告一次，正常保守退回不作为错误。

## 8. 验收门槛

### 8.1 逻辑与生命周期

- 所有语言范围有独立预期，覆盖非法/未完成结构、字符串/注释伪结构、嵌套/同标题/交叉、
  LF/CRLF 规范化、Unicode、EOF；不同来源相同输入不靠互相比对证明正确。
- Folds 构造输入复制、非法结果不覆盖旧值、空/清除语义、共享文档视图隔离、过期结果、
  内置/外部竞争、编辑映射、Reset、换语言、IME、卸载重挂载和回调重入。
- 相同可见集合不重建原生几何；无关折叠发布保持补全与选区。新隐藏范围不能盖住光标。
- 子词的独立边界表；正反向选区、软折行、组合字符、emoji/RTL Cluster、行首末、只读、
  超长词分片跨界；输入事件真正执行后才断言 caret 和文本。
- Expand/Shrink 精确往返，未就绪无猜测、半成品无越界、外部动作清除轨迹、颜色刷新不清除。
- Enter/重新缩进/粘贴都用“前文 + 操作 + 完整预期正文与选区 + Undo/Redo”断言；
  保护内容逐字节不变，Tab/Space 混用、空白行、无尾换行、错误/取消路径都覆盖。

### 8.2 窗口与延迟

本机独立 X11 + 合成器，Basic/Modern 亮暗、100%/150%。通过正常事件、真实剪贴板路径，
操作前保存并在可行时恢复测试会话剪贴板；只使用独立会话，关闭回收自有进程。
窗口观察折叠/滚动/选区/补全/IME，不把启动成功或逻辑测试当作 GUI 验收。

分别使用普通样例、10 MiB 多行配置文件、超长单行、至少十万候选的外部折叠输入。
大文件没有折叠时不虚构按钮；十万项样本必须测试提交、状态协调、编辑和取消，不只测构造器。
记录事件进入、正文事务/选区生效、首次有效绘制、事件循环心跳的最大/P95 间隔；对照当前
实现、相同文件/后端/缩放下的值。真实连续输入与缩放/滚动期间执行，不能以 API 返回时间代替。

2ms/64KiB/256项仅为初始合作预算，需测量调整；不通过扩大时间容差、丢弃正确性断言或
跳过大样本来通过。若最终事务/索引重建仍有明显阻塞，明确标记该项未完成并定位最小改动。

每切片运行 go test ./...；独立依赖另跑 GOWORK=off go test ./...，异步任务和快照增加针对性
race。公开契约检查三平台编译；Linux 本机窗口通过不等于 macOS/Windows 原生验证通过。
相邻 GOUI 开发版本若不兼容，单独记录其构建错误和版本，不让 go.work 掩盖已发布依赖结果。

## 10. 实现边界

- 自动整理任务最多提交 4096 个实际编辑。超过时通过 ConnectError 报告 ErrOperationLimit，正文和历史完全不变。
  这是约束最后一次同步 ApplyBatch 的预算，不能用拆成多个事务绕过。公开 ApplyEdits 的契约不变。
- 重新缩进：JSON/JSONC/JSON5、Go/JS/TS/CSS 按已知括号层级；TOML 表头保持同层，数组单独处理；
  Python 只对确认的括号续行调整，普通块缩进决定语义，不重新推断。XML/HTML 只改确认标签起始行，
  文本、CDATA、注释、raw-text 内容不动。YAML/Markdown 的 Reindent 保留 nil；仍有 Enter 辅助。
- 标签结构选区使用 TagRules.SelectionRanges，复用现有标签解析。只扫描预算内的完整标记区域；
  超大文档不从任意截断位置伪造 XML/HTML 解析起点。字符串内容选择目前要求同一逻辑行的完整引号证据。
- 选中范围的大小写转换仅复制所选范围；无选区时在 worker 从快照查找语言词。缩进粘贴直接分析剪贴板字符串，
  无须再复制当前全文。重新缩进和全局整理需要完整上下文，使用 64 KiB 分片快照。
- 外部折叠清除遇到 IME 投影时延后可见映射变化；离开投影后清除旧隐藏范围，再接收最新候选。
- 自定义 Reindent 与 Folding 回调必须响应 context；控件可拒绝迟到结果，无法强制中止调用方的 Go 函数。
