# 视图状态实施与验收

设计见 [视图状态](DesignViewState.md)。分支 feature/view-state，依赖 GOUI v0.7.0。

## 第一批：选区与视口

SaveState / RestoreState 及 ui.ViewState 别名已接入。快照只保留文档身份、修订、
有方向的提交选区、光标亲和性和文本锚点，不持有原生资源或正文副本。
保存只读取缓存；恢复请求使用已有布局队列，按文本位置优先测量，不抢焦点、不编辑正文。
普通输入/导航/换文档/卸载取消请求，滚动宿主的临时 Capture 控制器覆盖滚轮及滚动条输入，
释放时移除，不阻止正常分发。

包测试覆盖：

- 反向选区、亲和性、只读恢复、视口局部偏移与缓存读取不增加原生布局。
- 无效/异文档/过期快照拒绝，拒绝请求不破坏已有恢复任务。
- 显式选择、显露、按键、换文档和卸载取消，控制器按生命周期释放。
- 补全关闭回调启动新恢复时保留最新请求；预编辑捕获不提交投影内容。

第一批结构折叠与手动长行收起恢复尚待接入；原生窗口与跨平台验证在完整功能后执行。
