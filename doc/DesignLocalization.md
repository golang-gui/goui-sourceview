# 界面语言

SourceView 的编辑菜单和可选 FindBar 使用 GOUI `mlang`，内置英语 `en`、简中 `zh-CN`、
日语 `ja`、韩语 `ko`、德语 `de`、法语 `fr`、俄语 `ru`、阿拉伯语 `ar`。
地区标签按 GOUI 的 BCP 47 匹配契约处理，未匹配语言和 `und` 回退英语。
实现与验证见 [多语言验收](PlanLocalization.md)。

## 资源与职责

界面文本集中在 `internal/resource/text.go`，只依赖 `mlang` 和标准库。
每个 Getter 在包级定义一次，菜单和查找栏复用，不在构造控件或每帧计数时反复构造词条。
通用编辑术语与 GOUI 自身资源对齐；本模块不能导入 GOUI 的 internal/resource，
也不为共享这些词条扩大 GOUI 的公共 API。

- 编辑菜单：撤销、重做、剪切、复制、粘贴、删除、行移动/复制/删除、全选。
- FindBar：查询/替换提示、输入名称、选项和图标按钮的语义名称、计数中/查询过长/完成计数。
- 完成计数使用“匹配数：N”一类标签格式，避免将英语复数后缀规则套到其他语言。
  数值仍沿用 `%d`，不引入复数、日期或数字本地化子系统。

源码、查找/替换内容、应用提供的补全 Label/Text/Detail、日志和 error 值不参与翻译。
文档语言、Kind、命令编号、样式名、语义角色与动作保持稳定；界面语言不改变语法分析。
当前补全的语言标识与来源标签仍沿用既有约定，不在本次菜单/查找栏范围内变更。

## 切换与生命周期

应用在 GUI 线程调用 `mlang.SetLanguage(tag)`；后台发起时经 GOUI 的事件循环投递。
`mlang` 初始为英语，由应用选择何时采用系统语言；SourceView 不另行监听系统设置。

菜单每次打开时读取当前资源，已展开时通过原有 `MenuItem.SetLabel` 原地更新。
不重建动作或按译后字符串分派命令，保留选中项、可用状态与正常键盘/指针行为。
使用过菜单的视图在挂载期间持有语言连接，卸载断开，再次打开时重连。

FindBar 在构造时读取当前语言，挂载后通过原有语言信号更新提示、名称与当前计数状态。
输入框也加入同一个名称集合，语义快照不会残留固定英文。
切换不重建控件、清除查询/替换或重新修改正文；保留选择、历史、焦点及已完成计数。
卸载断开连接，重新挂载主动应用当前语言；关闭但仍挂载的栏继续更新文案。

长菜单文本按 GOUI 的自然宽度重新测量，受实际可用工作区限制。
查找栏继续采用既有窄宽度降级：隐藏次要动作/计数，保留输入和快捷键。
翻译不构成 RTL 布局镜像、系统高对比度、所有字体或母语校对的验收承诺。

实现依据是所依赖 GOUI 的 [mlang 契约](../../goui/mlang/mlang.go)、
[资源匹配](../../goui/mlang/string.go)、[菜单更新](../../goui/gui/menu.go)
及 [多语言设计](../../goui/doc/DesignLocalization.md)。这些是本地依赖源码与设计证据，
不从其他编辑器的国际化体系推断 GOUI 的线程、布局或资源行为。
