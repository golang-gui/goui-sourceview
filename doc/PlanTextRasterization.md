# 长行区域光栅化验收（2026-10-20）

GOUI 基线 `809083e`，实现提交 `e5d5331`；本仓基线 `f2a88c9`，
接口使用者迁移提交 `102639d`。通用修正在 GOUI，详细契约见
[区域光栅化设计](../../goui/doc/DesignTextRasterization.md)。本仓不添加专属 raster
后端；直接使用 GOUI 正常 DrawTextLayout。已更新现有原生颜色测试和窗口程序的
Rasterize 使用者，改为明确传入同一像素区域。

## 新增场景

`tests/window/editor/longlines` 从空编辑器设置一行 160,011 字节的原创 JSON，
也可用 `-file` 读取用户指定的既有单行文件。通过正常 DispatchEvent/CommitText
验证首尾定位、尾部插入、撤销、水平滚动、侧栏变化及重复绘制；检查完整模型内容、
有界可见摘录、语法色像素、原生请求尺寸及错误。分帧高亮允许在有限时间内完成，
不能把未着色的当前片段误当作光栅失败，也不能无期限等待。

初次窗口检查发现长行快照固定截取行首 64 KiB，尾部 caret 不在 VisibleRange。
现改为只读已缓存的原生几何，从视口的左上文字位置附近截取一个连续的原文区间；
不创建 native layout、不改变选区或滚动，仍限制 64 KiB 并保持 UTF-8 边界。
无几何缓存时保留行首降级。固定 10 DIP 字宽、80,000 字节的中英文样本独立断言
视口对应 byte=70000；移动回行首和无缓存查询也有回归。

## 验证记录

- Linux amd64 / Go 1.25.8 / Pango 1.50.6 / Cairo 1.16.0：`go test ./...`、
  `go test -race ./...` 通过。原生文字与 GUI 整合的验证另见 GOUI 同名 Plan。
- macOS 15.7.7 arm64：SourceView 包测试目标交叉编译后在原生主机运行，
  SHA-256 核对一致后执行全包原生测试通过；不将其等同于 macOS 窗口验收。
- Windows 测试目标交叉编译通过；GOUI 的远端原生运行被目标机拒绝访问，
  因此 Windows 像素/桌面验收仍未完成。

Linux 独立 Xvnc `:167` / Xfwm4 compositor on / llvmpipe：以下窗口场景全部
完成八个步骤，退出码 0（程序含 race instrumentation）：

| 样本 | Painter | 缩放 | 结果 |
| --- | --- | --- | --- |
| 原创 160,011 字节 JSON | Software | 1× | 通过，34 次原生区域请求 |
| 用户 157,862 字节 `1.json` | Software | 1× | 通过，38 次原生区域请求 |
| 原创 JSON | Software | 1.25× | 通过，30 次原生区域请求 |
| 原创 JSON | Software | 2× | 通过，51 次原生区域请求 |
| 原创 JSON | OpenGL | 1× | 通过，34 次原生区域请求 |

每个步骤保留完整内容、UTF-8、可见范围和语法像素断言。高亮分片期间的白色/普通
前景不直接判失败，必须在限定时间内出现预期颜色，原生错误立即失败。初版测试在
首帧前读取零分配、以及高亮完成前立即要求尾部颜色，曾失败；修正等待条件后仍
保留原预期，未删除断言。上述步骤耗时包含高亮、shaping、像素扫描和两次离屏绘制，
通常约 25–40 秒完成整组，不作单次编辑延迟或资源改善结论。

另用用户现有 `example/temp`、真实 Open 文件对话框选择 `/data/xuyang8/1.json`，
确认实际窗口显示语法色与水平滚动条，日志记录了该路径，没有再次崩溃。图片和
用户文件不提交；原生选择器可能更新最近文件记录，独立桌面在收尾关闭。

本机工作区测试通过。`GOWORK=off go test ./...` 在用户现有本地 replace 下也通过，
它仍引用本机 GOUI；另用 HEAD 的发行 go.mod 作临时 `-modfile`，真实依赖 GOUI
v0.2.0 的测试编译因新 Rasterize 签名失败。该失败是依赖发布条件，不能算独立发行通过。


## 单独保留的失败与发布条件

160 KiB 的连续单词切换 WrapWordChar 后，在 Pango GetExtents 的同步排版中超过
一分钟未返回。诊断主动 SIGQUIT，未计为成功或误报为原来的 native SIGSEGV。
默认窗口场景完成无折行长行；`-wrap` 保留相同样本的独立探测，没有缩短样本。
这与区域光栅化解决的完整位图分配不同，不声称本轮解决全部超长行排版成本。

GOUI 的新接口尚未发布，独立发行仍受依赖版本阻塞。仓库 go.mod 中用户已有的
本地 replace 和 example/temp 不属于本轮提交。发布前须升级实际可获取的 GOUI
版本并关闭工作区复验，不能将本机联调通过写成 v0.2.0 已支持新契约。
