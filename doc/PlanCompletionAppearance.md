## 调整与独立回归

- 补全专用面板/边框、普通及选中配色，不再借用正文选区颜色。
- 名称与较小、较弱的说明独立排版并对齐基线；名称突出前缀，长文本在 Cluster 边界省略。
- 测量候选集后固定自然尺寸和列宽，滚动不改变宽度；词首可见且在同一折行时对齐词首。
- 至多八个完整可见行和滚动提示，留白/边框/提示区域不执行候选，快照边界与点击几何一致。
- 显示片段至多十六个原生布局，省略时峰值十七个；未变状态不重复排版/着色。
  构建资源在事务完成后才发布；取消、原生错误及递归创建/度量/绘制不泄漏或使用已释放对象。

`completion_list_test.go` 使用独立的 10x20 DIP 字符度量，明确断言边框、列位置、基线、裁剪、
普通/选中前缀与说明颜色、滚动/小尺寸快照、完整说明属性和资源计数。
包含原生创建和着色期间取消、排版失败的一次报告、递归回调、重叠 Cluster 与 UTF-8 大小写
转换 byte 长度变化。资源压力样本为 64 项长名称与长说明，多页滚动验证 16/17 布局上限。

`completion_native_test.go` 在 Pango、DirectWrite、CoreText 上，分别使用 monospace/sans-serif
请求验证组合字符、中文、emoji 和 RTL 前缀：省略文本必须等于独立给定的 `prefix + …`，
实际宽度不超过用该参考文本原生测得的宽度加 0.01 DIP，基线必须在文字高度内。
这验证原生 shaping 和度量，不把字体名称请求当作已选中同一字型。

使用新窗口程序与修改前 `959a05f` 的源码快照复验：JSON 场景点击左侧留白后，旧实现
以 `padding accepted a candidate` 退出失败，新实现通过。相同场景旧宽度 560 DIP，
新宽度 350 DIP；这是该固定样本的布局结果，不作性能或所有候选的尺寸承诺。
旧截图中三种新面板专用颜色均不存在，新截图能明确采样到这些颜色。
